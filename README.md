Entry for the [make.fun](https://make.fun/c/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty **One-Sentence Absurd Invention Pitch**: one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance.

## How it works

`main.ts` (Node 22, no network, fully deterministic) writes a single sentence of at most 220 characters to `/output/entry.txt`:

> The Midnight Fridge stays locked after midnight until you slide a signed apology note under its door for coming back to stare at the leftovers again.

Run it with:

```sh
node main.ts
```

The output directory can be overridden with the `OUTPUT_DIR` environment variable.
